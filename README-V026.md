# Core-Orça V26 — Lista de Materiais

1. Execute `supabase-v026-lista-materiais.sql` no SQL Editor do Supabase.
2. Publique `index.html`, `app.js` e `style.css` no GitHub Pages.
3. Faça Ctrl+F5.

A nova aba **Lista de Materiais** usa os materiais cadastrados da empresa, pesquisa nos selects, permite vínculo com Orçamento ou Recibo, carrega materiais do vínculo, usa o custo cadastrado como valor unitário, permite editar quantidade/custo/observação, salva no Supabase, edita/exclui e gera PDF/impressão.
