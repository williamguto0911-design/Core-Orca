# Core-Orça V027 — Lista de Materiais

Novidades:
- Lista de Materiais pode ser vinculada a uma Ordem de Serviço (OS).
- Ao selecionar uma OS, o cliente é preenchido automaticamente.
- O botão “Carregar materiais do vínculo” também carrega os materiais existentes na OS.
- Novo campo “Responsável pela emissão”.
- Responsável aparece na listagem, visualização e PDF/impressão.

## Atualização a partir da V026
1. Execute `supabase-v027-lista-materiais-os-responsavel.sql` no SQL Editor do Supabase.
2. Substitua `index.html` e `app.js` no site pelos arquivos desta versão.
3. `style.css` pode ser substituído também para manter o pacote completo, embora não haja alteração visual obrigatória nesta versão.
4. Publique e faça Ctrl+F5.
