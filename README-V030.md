# Core-Orça V030 — Recibo com importação automática

Ao criar ou editar um recibo, é possível vincular Orçamento, Lista de Materiais ou Ordem de Serviço. Ao selecionar o documento, cliente e itens são carregados automaticamente e substituem os itens importados do vínculo anterior. Os itens permanecem editáveis.

## Instalação
1. Execute `supabase-v030-recibo-vinculos.sql` no SQL Editor do Supabase.
2. Substitua `app.js` pelo arquivo desta versão.
3. Publique e faça Ctrl+F5.
