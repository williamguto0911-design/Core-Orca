# Core Orça V039 — Reposição de Estoque

Adicionado o menu **Reposição de Estoque**.

- Exibe materiais cujo estoque atual é menor ou igual ao estoque mínimo.
- Seleção individual por material.
- Botão **Selecionar todos / Desmarcar todos**.
- Campo de quantidade e observações por item.
- Quantidade inicial sugerida para recompor a diferença até o mínimo (mínimo de 1 unidade).
- Botão **Gerar PDF** usando o padrão de documentos já existente no Core Orça.
- No PDF, o campo **Cliente** usa os dados da empresa cadastrada em Configurações.
- O menu utiliza a mesma permissão do módulo **Estoque**.
