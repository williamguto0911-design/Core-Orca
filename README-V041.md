# Core Orça V041 — Unifilar CAD e símbolos personalizados

## Implementado
- Visual escuro CAD inspirado nos exemplos fornecidos.
- Biblioteca técnica: entrada, medidor, transformador, gerador, quadro, disjuntor, IDR, DPS, fusível, seccionadora, circuitos, cargas, barramentos N/PE e barramento pente.
- Sistemas monofásico, bifásico e trifásico.
- Ligações ortogonais, grade e organização automática.
- Múltiplos IDRs por quadro.
- Propriedades de polos, corrente, Icc/Icn, IΔn, potência, tensão e FP.
- Biblioteca de símbolos personalizados por empresa.
- Editor vetorial simples para desenhar e salvar novos símbolos.
- Integração de materiais e documentos mantida.

## Banco
Execute `supabase-v041-unifilar-simbolos.sql` no Supabase antes de usar a criação de símbolos.

## Nota normativa
A interface usa convenções gráficas técnicas inspiradas na IEC 60617. A IEC 60617 DB é a fonte oficial dos símbolos normalizados. Símbolos personalizados criados pelo usuário não são automaticamente certificados como símbolos IEC/ABNT.
