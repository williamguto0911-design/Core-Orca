# Core Orça V048 — Lista de Materiais, editor de texto e atalhos

## Alterações
- Lista de Materiais: troca de tópico somente por arrastar e soltar; removido seletor de tópico por material.
- Botão Editar em cada material da lista, com quantidade, unidade e observações.
- Observações com editor rico: negrito, itálico, sublinhado, texto vermelho e múltiplas linhas com Enter.
- Atalhos: Ctrl+L cria nova Lista de Materiais quando o menu Lista de Materiais está aberto; Ctrl+M cria novo material quando Materiais está aberto.
- Dentro do editor de texto: Ctrl+N negrito, Ctrl+I itálico, Ctrl+S sublinhado.
- Itens de materiais/serviços nos editores de Orçamento, Recibo e OS agora possuem Editar e Excluir.
- Popups ampliados e layouts responsivos para evitar sobreposição de campos.
- Não há SQL novo nesta versão.

## Instalação
Substitua index.html, app.js e style.css pelos arquivos desta versão e faça Ctrl+F5 no navegador.
