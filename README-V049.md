# Core Orça V049

## Ajustes
- Botão de cor do editor rico agora funciona como alternância: vermelho ↔ preto.
- A alternância atua sobre a seleção ou sobre o texto digitado a partir do cursor.
- Formatações de observações (negrito, itálico, sublinhado, vermelho/preto e quebras de linha) são preservadas na Lista de Materiais, visualização e PDF.
- Mantidos os atalhos Ctrl+N, Ctrl+I e Ctrl+S dentro do editor.

## Instalação
Não há SQL novo. Publique os arquivos da V049 e faça Ctrl+F5.
